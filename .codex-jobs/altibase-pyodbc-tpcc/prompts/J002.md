# Job J002: Altibase driver reset and load

## Goal

Add the pyodbc-backed Altibase driver skeleton with DSN connection, schema reset, DDL execution, tuple loading, cleanup, and CLI discovery.

## Source Material

- `ALTIBASE_PYODBC_EXECUTION_DESIGN.md`
- `ALTIBASE_TEST_NOTES.md`
- DDL/config from J001: `pytpcc/tpcc_altibase.sql`, `pytpcc/ALTIBASE_ODBC_EXAMPLE`
- Driver patterns: `pytpcc/drivers/postgresqldriver.py`, `pytpcc/drivers/sqlitedriver.py`, `pytpcc/drivers/abstractdriver.py`
- Runtime flow: `pytpcc/tpcc.py`, `pytpcc/runtime/loader.py`

## Scope

- Add `pytpcc/drivers/altibasedriver.py`.
- Implement connection/config/reset/load-only driver behavior.
- Include transaction method stubs only if needed for imports; full transaction bodies belong to J003.
- Do not use `/home/et16/work/altibase-python-driver`.

## Required Implementation

1. Read the source material before editing.
2. Implement `AltibaseDriver(AbstractDriver)` with `name == "altibase"` so `python3 tpcc.py --print-config altibase` discovers it from `pytpcc/`.
3. Use lazy `pyodbc` import inside `_connect()` or `loadConfig()`, not at module import time.
4. Implement `DEFAULT_CONFIG` matching `pytpcc/ALTIBASE_ODBC_EXAMPLE`.
5. Convert `ConfigParser` strings explicitly:
   - `connection-timeout` to int
   - `max-retries` to int
   - `retry-delay` to float
   - `fast-executemany` to bool using a real boolean parser, not `bool(value)`
6. Build the pyodbc connection string as `DSN=<dsn>;UID=<user>;PWD=<password>`.
7. Implement `loadConfig(config)`:
   - connect with pyodbc.
   - create cursor.
   - if `config["reset"]` is true, drop existing TPC-C tables in the documented dependency order.
   - ignore only "table not found" class errors, including SQLSTATE `42S02` or vendor code `200753`.
   - execute `self.ddl` statement by statement.
   - commit after successful reset/DDL.
8. Implement DDL statement splitting for the current DDL shape:
   - remove full-line `--` comments.
   - strip blank lines.
   - split on `;`.
9. Implement `loadTuples(tableName, tuples)` with generated qmark placeholders and `executemany`.
   - Set `cursor.fast_executemany` from config only when that attribute is available.
10. Implement `loadFinish()` as commit.
11. Implement `cleanup()` idempotently for cursor and connection.
12. Implement `getNumberWH()` as `SELECT MAX(W_ID) FROM WAREHOUSE`.
